## 3. Análise e Classificação do Dataset Iris

A terceira atividade teve como objetivo trabalhar com um conjunto de dados real utilizando conceitos de **análise de dados e Machine Learning**.

Foi utilizado o dataset **Iris**, contendo informações sobre diferentes espécies de flores.

### Obtenção dos dados

Sem utilizar a função automática do Scikit-Learn para carregar o conjunto de dados, foi utilizado o arquivo `Iris.csv` disponibilizado pelo Kaggle. O arquivo foi localizado pelo caminho fornecido pela plataforma e carregado utilizando o Pandas.

### Análise dos dados

Após o carregamento, foram realizadas etapas de exploração e preparação dos dados, incluindo:

- Leitura do arquivo CSV
- Visualização das primeiras linhas
- Análise das colunas
- Verificação dos tipos de dados
- Identificação de possíveis valores nulos
- Separação das características e do resultado esperado
- Preparação dos dados para o modelo

### Preparação para Machine Learning

Os dados foram organizados para que as características das flores fossem utilizadas como variáveis de entrada e a espécie da flor fosse utilizada como variável de saída.

Essa etapa é importante para preparar o conjunto de dados antes da aplicação dos algoritmos de Machine Learning.

### Treinamento e avaliação

Após a preparação dos dados, foi realizado o treinamento de um modelo de classificação utilizando Python e bibliotecas de Machine Learning.

O modelo foi posteriormente avaliado utilizando os dados separados para teste, permitindo verificar seu desempenho na classificação das espécies de flores.

Essa atividade possibilitou aplicar na prática conceitos de **Machine Learning**, desde a obtenção e preparação dos dados até o treinamento e avaliação de um modelo.
