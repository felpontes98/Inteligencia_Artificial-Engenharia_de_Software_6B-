# Disciplina de Inteligência Artificial

Este repositório reúne as atividades, exercícios e projetos desenvolvidos durante a disciplina de Inteligência Artificial.

## Conteúdo

Os arquivos deste repositório apresentam atividades práticas realizadas ao longo da disciplina, utilizando principalmente Python, Google Colab e ferramentas de Machine Learning.

### Exercícios de Python

O notebook de exercícios contém 50 atividades envolvendo conceitos básicos e intermediários de programação, como:

- Variáveis e tipos de dados
- Entrada e saída de informações
- Estruturas condicionais
- Estruturas de repetição
- Listas e dicionários
- Manipulação de strings
- Funções
- Recursão
- Algoritmos de ordenação
- Busca binária
- Matrizes
- Manipulação de arquivos e bibliotecas
- Jogos e pequenos programas

### Atividade de Machine Learning — Dataset Iris

Nesta atividade foi desenvolvido um modelo de **Machine Learning** utilizando o dataset **Iris**, obtido diretamente pelo Kaggle. O objetivo foi realizar uma análise inicial dos dados e utilizar o algoritmo **Support Vector Machine (SVM)** para classificar as diferentes espécies de flores.

Durante o desenvolvimento da atividade foram realizadas as seguintes etapas:

- Carregamento do dataset Iris
- Análise e verificação dos dados
- Identificação de valores ausentes
- Análise estatística das características
- Criação de gráficos para exploração dos dados
- Separação dos dados em treinamento e teste
- Treinamento do modelo utilizando SVM
- Realização das previsões
- Avaliação do modelo por meio da acurácia
- Análise do relatório de classificação
- Criação da matriz de confusão

A atividade permitiu aplicar na prática conceitos de **análise exploratória de dados, classificação e avaliação de modelos de Machine Learning**.
